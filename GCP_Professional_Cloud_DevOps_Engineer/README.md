# Google Cloud Certified: Professional Cloud DevOps Engineer

Welcome to the comprehensive master study curriculum for the **Google Cloud Certified Professional Cloud DevOps Engineer** examination.

A Professional Cloud DevOps Engineer is responsible for generating efficient development operations that can balance service reliability and delivery speed. They are skilled at using Google Cloud Platform to build software delivery pipelines, deploy and monitor services, and manage and learn from incidents.

---

## Exam Blueprint & Domain Weightings

| Domain | Exam Section | Weight | Focus Areas |
| :---: | :--- | :---: | :--- |
| **Domain 1** | [Applying Site Reliability Engineering Principles to a Service](./Domain_1_SRE_Principles_Service_Reliability/Study_Guide.md) | **22%** | SLIs, SLOs, SLAs, Error Budgets, Toil Budgeting & Reduction, Capacity Planning, Chaos Engineering. |
| **Domain 2** | [Building and Implementing CI/CD Pipelines for a Service](./Domain_2_CICD_Pipelines_Deployment_Strategies/Study_Guide.md) | **25%** | Cloud Build, Cloud Deploy, Artifact Registry, Skaffold, Canary/Blue-Green/Shadow rollouts, GitOps with Config Sync. |
| **Domain 3** | [Implementing Service Monitoring Strategies](./Domain_3_Service_Monitoring_Observability/Study_Guide.md) | **20%** | Cloud Monitoring (MQL), Cloud Logging (Log Router, Sinks), Cloud Trace, Cloud Profiler, Error Reporting, Managed Service for Prometheus. |
| **Domain 4** | [Managing Service Incidents](./Domain_4_Incident_Management_Postmortems/Study_Guide.md) | **18%** | Incident command hierarchy (Incident Commander, Ops, Comms), Alert routing & notification channels, Mitigating degraded service, Blameless postmortems. |
| **Domain 5** | [Applying SRE Concepts to Security & Governance](./Domain_5_Security_Governance_SRE_Operations/Study_Guide.md) | **15%** | Binary Authorization, Secret Manager, Workload Identity Federation, Service Accounts & least privilege, VPC Service Controls, Cloud KMS. |
