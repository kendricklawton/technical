## 2. Domain Distribution Across Practice Exams

All practice exams are balanced to reflect the official `SAP-C02` blueprint percentages:

| Domain | Official Weight | Key Competencies Tested |
| :--- | :---: | :--- |
| **Domain 1: Design Solutions for Organizational Complexity** | 26% | AWS Organizations, SCPs, Control Tower, Transit Gateway, Centralized Inspection VPCs, IAM Identity Center. |
| **Domain 2: Design for New Solutions** | 29% | Multi-region Active-Active, Event-driven architectures, DynamoDB Global Tables, Serverless microservices, PrivateLink. |
| **Domain 3: Continuous Improvement for Existing Solutions** | 25% | FinOps cost optimization, ElastiCache Redis, S3 Intelligent-Tiering, Karpenter compute consolidation, AWS WAF. |
| **Domain 4: Accelerate Workload Migration and Modernization** | 20% | Large-scale database migration (SCT/DMS), Server migration (AWS MGN), Storage migration (DataSync/Snowball), App2Container. |
