# GCP Professional Cloud Architect (PCA) — Practice Exams Suite

Welcome to the full-length scenario practice exams for the **Google Cloud Certified: Professional Cloud Architect** certification.

---

## Exam Blueprint & Domain Allocation

- **Format:** 15 multi-paragraph, complex enterprise scenario questions per exam with single answer selection (A–D).
- **Passing Target:** $\ge 80\%$ (12 / 15 correct) on all practice exams before taking the official exam.
- **Time Allocation:** 75 minutes per practice exam (real exam is 120 minutes for 50 questions).

| Domain | Focus Area | Exam Weight |
| :--- | :--- | :--- |
| **Domain 1** | Designing and Planning a Cloud Solution Architecture | ~24% |
| **Domain 2** | Managing and Provisioning Infrastructure & Networking | ~15% |
| **Domain 3** | Designing for Security, Identity, and Compliance | ~21% |
| **Domain 4** | Analyzing and Optimizing Technical and Business Processes | ~19% |
| **Domain 5** | Reliability, Operations & Official Case Studies (EHR, Cymbal, Mountkirk, TerramEarth) | ~21% |
