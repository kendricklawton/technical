### Task 1: Argo CD Sync Phases & PreSync Database Migration Hook (Weight: 7%)
**Scenario:** A deployment `web-app` requires a database migration script to run and finish successfully before the new application pods are deployed. If the migration fails, the sync must abort immediately.
**Requirements:**
1. Create a Kubernetes `Job` named `db-migration-job` in namespace `production`.
2. Configure Argo CD annotations:
   - `argocd.argoproj.io/hook: PreSync`
   - `argocd.argoproj.io/hook-delete-policy: BeforeHookCreation`
3. Job must execute container image `postgres:16-alpine` running `echo Migrating DB schema; exit 0`.

**Solution:**
```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: db-migration-job
  namespace: production
  annotations:
    argocd.argoproj.io/hook: PreSync
    argocd.argoproj.io/hook-delete-policy: BeforeHookCreation
spec:
  template:
    spec:
      restartPolicy: Never
      containers:
        - name: migrate
          image: postgres:16-alpine
          command: ["sh", "-c", "echo Migrating DB schema; exit 0"]
```
**Verification:**
```bash
kubectl apply -f migration-hook.yaml
argocd app sync web-app
```

### Task 2: Crossplane Connection Secret Propagation (Weight: 8%)
**Scenario:** Configure a Crossplane `Composition` so that credentials generated by a managed MySQL database are automatically published into a Kubernetes Secret in the tenant namespace.
**Requirements:**
1. Specify `writeConnectionSecretsToNamespace: crossplane-system` on the managed resource.
2. In the Composition, configure `publishConnectionDetailsWithStoreConfigRef` or patch connection details to the Composite Resource Claim.

**Solution:**
```yaml
apiVersion: apiextensions.crossplane.io/v1
kind: Composition
metadata:
  name: mysql-with-secrets
spec:
  compositeTypeRef:
    apiVersion: database.platform.io/v1alpha1
    kind: XDatabase
  resources:
    - name: mysql-instance
      base:
        apiVersion: rds.aws.upbound.io/v1beta1
        kind: Instance
        spec:
          forProvider:
            region: us-east-1
            engine: mysql
          writeConnectionSecretToRef:
            namespace: crossplane-system
            name: mysql-generated-creds
      patches:
        - type: ToCompositeFieldPath
          fromFieldPath: metadata.name
          toFieldPath: status.dbInstanceId
```

### Task 4: Argo Rollouts Step-by-Step Canary Weight Progression (Weight: 7%)
**Scenario:** Configure an Argo `Rollout` for `catalog-api` in namespace `catalog` with 10 replicas. Progressively route traffic:
- 10% for 5 minutes.
- 30% for 10 minutes.
- 60% for 15 minutes.
- 100% full promotion.

**Solution:**
```yaml
apiVersion: argoproj.io/v1alpha1
kind: Rollout
metadata:
  name: catalog-api
  namespace: catalog
spec:
  replicas: 10
  strategy:
    canary:
      steps:
        - setWeight: 10
        - pause: { duration: 5m }
        - setWeight: 30
        - pause: { duration: 10m }
        - setWeight: 60
        - pause: { duration: 15m }
        - setWeight: 100
  selector:
    matchLabels:
      app: catalog-api
  template:
    metadata:
      labels:
        app: catalog-api
    spec:
      containers:
        - name: catalog
          image: ghcr.io/enterprise/catalog:v2.0.0
          ports:
            - containerPort: 8080
```

### Task 5: Kyverno PolicyException Scoped Exemption (Weight: 6%)
**Scenario:** A legacy logging agent `fluentbit-legacy` in namespace `logging` requires `hostPath` access. Create a Kyverno `PolicyException` exempting this pod from the cluster policy `disallow-hostpath` without modifying the global policy.

**Solution:**
```yaml
apiVersion: kyverno.io/v2alpha1
kind: PolicyException
metadata:
  name: allow-fluentbit-hostpath
  namespace: logging
spec:
  exceptions:
    - policyName: disallow-hostpath
      ruleNames:
        - validate-no-hostpath
  match:
    any:
      - resources:
          kinds: [Pod]
          namespaces: [logging]
          names: ["fluentbit-legacy*"]
```

### Task 6: KEDA Autoscaling with Redis Stream Trigger (Weight: 7%)
**Scenario:** Auto-scale worker deployment `order-stream-processor` in namespace `orders` between 0 and 25 replicas based on the length of Redis Stream `orders_stream` in consumer group `processor_group`.
**Requirements:**
1. ScaledObject target: `order-stream-processor`.
2. Trigger type: `redis-streams`.
3. Stream: `orders_stream`, Group: `processor_group`.
4. Pending entries threshold: `10`.

**Solution:**
```yaml
apiVersion: keda.sh/v1alpha1
kind: ScaledObject
metadata:
  name: redis-stream-scaler
  namespace: orders
spec:
  scaleTargetRef:
    name: order-stream-processor
  minReplicaCount: 0
  maxReplicaCount: 25
  triggers:
    - type: redis-streams
      metadata:
        address: redis.messaging.svc:6379
        stream: orders_stream
        consumerGroup: processor_group
        pendingEntriesCount: "10"
```

### Task 7: Multi-Window Multi-Burn-Rate Prometheus Alert (Weight: 7%)
**Scenario:** Create a `PrometheusRule` triggering a SEV-1 page when a $6\times$ burn rate is sustained over a 6-hour window and verified by a 30-minute short window for a 99.9% SLO service.

**Solution:**
```yaml
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  name: slo-burnrate-6x
  namespace: core
spec:
  groups:
    - name: slo.burnrate.6x
      rules:
        - alert: ServiceBurnRate6x
          expr: |
            (
              sum(rate(http_requests_total{job="checkout-api",status=~"5.."}[6h]))
              /
              sum(rate(http_requests_total{job="checkout-api"}[6h]))
              > 6 * 0.001
            )
            and
            (
              sum(rate(http_requests_total{job="checkout-api",status=~"5.."}[30m]))
              /
              sum(rate(http_requests_total{job="checkout-api"}[30m]))
              > 6 * 0.001
            )
          labels:
            severity: page
          annotations:
            summary: "5% of monthly error budget consumed within 6 hours"
```

### Task 11: Gateway API Path Rewriting & Prefix Stripping (Weight: 6%)
**Scenario:** Configure an `HTTPRoute` rule so that external requests to `https://api.internal/billing/*` have the `/billing` prefix stripped before forwarding to backend service `billing-svc` at `/`.

**Solution:**
```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: billing-rewrite-route
  namespace: billing
spec:
  parentRefs:
    - name: shared-gateway
      namespace: platform-gateway
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /billing
      filters:
        - type: URLRewrite
          urlRewrite:
            path:
              type: ReplacePrefixMatch
              replacePrefixMatch: /
      backendRefs:
        - name: billing-svc
          port: 8080
```

### Task 14: Automated Canary Rollback on Analysis Failure (Weight: 7%)
**Scenario:** Deploy an Argo `Rollout` paired with an `AnalysisTemplate`. If the Prometheus error rate metric exceeds 2%, Argo Rollouts must automatically abort the rollout and restore the stable version.

**Solution:**
```yaml
apiVersion: argoproj.io/v1alpha1
kind: Rollout
metadata:
  name: payment-rollout
  namespace: payments
spec:
  replicas: 4
  strategy:
    canary:
      analysis:
        templates:
          - templateName: error-rate-check
        args:
          - name: service-name
            value: payment-rollout
      steps:
        - setWeight: 25
        - pause: { duration: 5m }
        - setWeight: 100
  selector:
    matchLabels:
      app: payment-api
  template:
    metadata:
      labels:
        app: payment-api
    spec:
      containers:
        - name: payment
          image: ghcr.io/enterprise/payment:v2.0.0
```

### Task 15: Pod Security Admission Labeling on Tenant Namespaces (Weight: 6%)
**Scenario:** Apply baseline Pod Security Standards across all existing non-system namespaces using a bash one-liner, enforcing `restricted` version `v1.31`.

**Solution:**
```bash
for ns in $(kubectl get ns -o jsonpath='{.items[*].metadata.name}'); do
  if [[ "$ns" != kube-* && "$ns" != "default" ]]; then
    kubectl label --overwrite namespace "$ns" \
      pod-security.kubernetes.io/enforce=restricted \
      pod-security.kubernetes.io/enforce-version=v1.31 \
      pod-security.kubernetes.io/warn=restricted \
      pod-security.kubernetes.io/warn-version=latest
  fi
done
```
